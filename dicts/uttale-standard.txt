# uttale.txt — ord som uttales annerledes enn de staves
#
# Format: ord  lydform   (ett ord per linje, mellomrom eller tab mellom)
# Sett ' foran vokalen som har trykk når trykket ikke ligger der rim-bm gjetter:
#   igjen  ij'enn
# Lydformen brukes både til rim og stavelsestelling. Linjer som starter med # hoppes over.
# Legg til egne ord nederst. rim-bm bygger indeksen på nytt neste gang fila endres.
#
# Regler rim-bm bruker uten denne fila: -ld → -ll (kald), -nd → -nn (land),
# -rd → -r (ord), -gt → -kt (sagt), -dt → -tt (godt), ei → æi (vei),
# o foran dobbel konsonant → å (kropp, flott). Ordene under er unntak og småord.
